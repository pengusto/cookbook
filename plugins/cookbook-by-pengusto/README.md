# Cookbook by Pengusto

Version 0.7.0 · Codex · plain

18 workflows for planning a project, checking progress, recovering chat context, reviewing exposure and legal questions, preparing a release, drafting change notes and finishing a chat. Open a fresh host session after installation, then invoke a workflow with your request.

| Workflow | Invocation |
|---|---|
| Explain the Cookbook | `$explain-the-cookbook` |
| Find Our Work | `$find-our-work` |
| Catch Me Up | `$catch-me-up` |
| Where Were We? | `$where-were-we` |
| How Do I Start? | `$how-do-i-start` |
| Finish My Prompt | `$finish-my-prompt` |
| Which Name Wins? | `$which-name-wins` |
| You Got This | `$you-got-this` |
| Am I Making Progress? | `$am-i-making-progress` |

Start with a small request: ask the planning workflow for a three-project portfolio plan, or ask the release-readiness workflow to review the current repository without publishing. Reviews report findings and limits; they do not certify security or legal compliance.

Install one naming variant per host. Before switching, preserve the installed package, natively uninstall this plugin and remove only its marketplace registration, then install the replacement. Avoid unintended duplicate installations; existing standalone aliases are not removed automatically. Preserve hidden manifest folders when extracting.

Local tools and Git may be required; repository scans use Python 3.10+. Optional scanners are not installed automatically. This skill bundle includes no hooks, background service or MCP server. Publication, deletion and other external actions require authorization. MIT; individual licenses and source provenance are included in LICENSE and SOURCES.json.
