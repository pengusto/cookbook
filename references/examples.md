# Example routing

## Simple website

Prompt: “Build a small German portfolio for my three projects.”

Recommend:

- product promise and page outline;
- responsive UI and accessibility;
- browser smoke;
- optional SEO and i18n only if English audience or search visibility matters.

Skip Let Him Grill and a large ticket tree when the path is clear. End with one
next action: create the smallest portfolio page and inspect it locally.

## News and content product

Prompt: “Create a newsroom where agents draft articles and a person approves them.”

Recommend:

- editorial workflow and human approval gate;
- source and evidence contract;
- AI-content and image-rights labeling;
- realistic fixture text with Stop Slop;
- UI states for drafting, checking, blocked, approved, and published;
- durable tickets and a browser smoke;
- Let Him Grill if role boundaries, data ownership, or publication behavior are
  still undecided.

End with a small end-to-end draft → review → approval slice.

## Browser extension

Prompt: “Make a Chrome extension that puts expensive tabs to sleep.”

Recommend:

- smallest Top-10 → Sleep → Wake flow;
- honest distinction between estimates and exact browser data;
- protected tabs and failure states;
- Manifest permissions and privacy copy;
- unpacked browser smoke and deterministic packaging;
- license decision before public source release;
- store material only after the core behavior passes.

Skip accounts, analytics, and automatic rules unless the product evidence makes
them necessary. End with the first real browser smoke.
