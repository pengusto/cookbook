# Recap edge cases

- Early history unavailable: “The original request is not visible. The earliest available goal is provisional.” Report only visible progress; do not invent the missing beginning.
- User changes “publish this” to “local review only”: record the approved scope change; publication is replaced, not an outstanding obligation.
- Assistant suggests analytics but user never agrees: do not add analytics to open commitments.

Consult these examples when history or scope is ambiguous.
