# Contributing

Open an issue or pull request in https://github.com/pengusto/cookbook. Keep changes focused and avoid sharing credentials, personal project data or private chat transcripts. For a sensitive vulnerability, use GitHub's private vulnerability reporting option if available; do not include exploit credentials in a public issue. No response-time commitment is made.

Edit workflow instructions only in `skills/<stable-id>/`; update reviewed file hashes in `catalog.json` when source content changes. `plain` and `kitchen` are generated alternative naming styles, not separate workflows. Keep all eight READMEs aligned when installation or capabilities change; disclose machine-translated text until reviewed by a fluent speaker.

Run `python3 scripts/launch_check.py`. Generated `site/`, `dist/`, local source registries and `.scratch/` are not committed. Preserve source licenses and imported `history/*` branches. Package validation does not replace host behavior testing. Include the host/version and synthetic test steps for runtime changes.
