THE SITE ITSELF

Small site.
Clear boundaries.

This static site contains no analytics, advertising SDKs, remote fonts, embedded social content or cookie-setting scripts. The prompt-copy button uses your browser’s clipboard only after you activate it.

Hosting

In a local preview, requests go to your local preview server. If published on GitHub Pages, GitHub receives information needed to deliver the site and states that visitor IP addresses are logged for security purposes. See GitHub Pages data collection and GitHub’s privacy statement.

Downloads and links

Downloads are served from the same host. GitHub and documentation links take you to external services only when followed. The downloadable skill does not itself run a service or collect data; an agent’s processing is governed by that agent and the environment in which you use it.

Before public publication

This is a pre-publication site. The maintainer still needs to confirm any applicable operator identification and complete privacy contact and controller information before an approved public launch. This page is not presented as a complete legal notice.
