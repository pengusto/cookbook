# Recipe illustration reserve / Rezeptbild-Vorrat

Two historical alternatives, retained for possible future Cookbook recipes. Before creating new recipe artwork, check whether one of these variants fits; check the current catalog first so dishes are not accidentally duplicated. These are not newly generated or unused original designs: the images were rearranged from existing Cookbook illustrations.

- `untangle-this-chat.webp`: bruschetta trio, rearranged from `which-name-wins`.
- `help-me-focus.webp`: lentil stew, rearranged from `catch-me-up`.

Each sheet has a dish cutout and four ingredient cutouts in `cutouts/`. `SOURCES.json` preserves the original descriptions, source IDs, dimensions and SHA-256 hashes. The filenames record their earlier proposed roles, not a current assignment. Review visual suitability and rights/provenance before reuse. These files are reserves, not active runtime assets.

Zwei historische Varianten für mögliche künftige Cookbook-Rezepte. Vor neuen Rezeptbildern prüfen, ob eine Variante passt; zuerst den aktuellen Katalog auf bereits vergebene Motive prüfen. Dies sind keine neu generierten, unbenutzten Originalmotive: Die Bilder wurden aus vorhandenen Cookbook-Illustrationen neu zusammengestellt.

- `untangle-this-chat.webp`: Bruschetta-Trio aus `which-name-wins`.
- `help-me-focus.webp`: Linseneintopf aus `catch-me-up`.

Zu jedem Bild gibt es einen Gericht-Freisteller und vier Zutaten-Freisteller in `cutouts/`. `SOURCES.json` bewahrt Beschreibungen, Quellen, Größen und SHA-256-Prüfsummen. Die Dateinamen dokumentieren frühere Vorschläge, keine aktuelle Zuordnung. Vor Wiederverwendung Eignung und Herkunft/Rechte prüfen. Die Dateien sind Vorrat und keine aktiven Runtime-Assets.
